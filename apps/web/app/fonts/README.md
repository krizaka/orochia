# Fonts

Variable fonts (Latin subset, `wght` axis) shipped with the app and loaded by `next/font/local` in `app/layout.tsx`:

| File | Family | Source | License |
| :--- | :--- | :--- | :--- |
| `outfit-latin-wght.woff2` | Outfit | [Fontsource](https://fontsource.org/fonts/outfit) / Google Fonts | SIL Open Font License 1.1 |
| `plus-jakarta-sans-latin-wght.woff2` | Plus Jakarta Sans | [Fontsource](https://fontsource.org/fonts/plus-jakarta-sans) / Google Fonts | SIL Open Font License 1.1 |

The OFL allows bundling and redistribution with software; the fonts are not sold on their own.
