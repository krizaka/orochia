## Ce que les autres voient

- Votre **nom d’utilisateur** et votre page publique, orochia.com/@votrenom.
- Votre **nom affiché**, votre photo, votre couverture, votre présentation et vos liens, si vous les ajoutez. Plusieurs personnes peuvent avoir le même nom affiché. Personne ne partage un nom d’utilisateur.
- Votre nom n’apparaît dans les enchères et les défis que sous un pseudonyme, comme Enchérisseur 2 ou Contributeur 3. Vous voyez **Vous** pour le vôtre.

## Ce qui reste privé

- Votre **adresse courriel.** Elle sert à vous connecter et aux notifications que vous gardez.
- Votre **date de naissance.** Orochia s’en sert pour confirmer que vous avez 18 ans ou plus. Elle n’est jamais affichée.
- Les données de votre carte. Elles se saisissent sur la page du fournisseur de paiement et n’atteignent jamais Orochia.
- Votre mode de versement, si vous êtes créateur. Il est stocké chiffré et n’est montré qu’en partie.

## Vos réglages

Ouvrez **Paramètres**. Vous y trouverez :

| Section | Ce qu’elle fait |
| :--- | :--- |
| Profil | Nom, photo, couverture, présentation |
| Liens | Votre site et vos liens sociaux |
| Confidentialité | Qui peut vous écrire |
| Notifications | Ce que vous apprenez, et comment |
| Versements | Pour les créateurs : où va votre argent |
| Modes de connexion | Comment vous vous connectez |
| Comptes bloqués | Les personnes qui ne peuvent ni vous écrire, ni vous suivre, ni vous demander en contact |
| Défis | Pour les créateurs : demandes et offres minimales |

## Votre langue

Orochia parle français et anglais. Utilisez le sélecteur de langue (le globe) dans la barre du site. Votre compte garde la langue dans laquelle vous lisez Orochia : les courriels et les notifications push y sont rédigés, quelle que soit la personne à l’origine de l’événement. La cloche suit la langue de la page que vous consultez.

## Vos données

Lisez la [politique de confidentialité](/legal/privacy) pour savoir ce qu’Orochia conserve et pourquoi. La page explique aussi comment poser une question sur vos données.

## Se déconnecter sur un téléphone partagé

Quand vous vous déconnectez de l’appli, elle oublie votre session et efface ce qu’elle avait stocké. La prochaine personne qui utilise ce téléphone ne voit jamais votre compte.
