## Ce qu’une vidéo demande

Les mots ci-dessous sont définis une seule fois dans le [Vocabulaire](/docs/vocabulary).

Chaque vidéo porte une étiquette qui dit qui peut la regarder.

| Étiquette | Qui peut regarder |
| :--- | :--- |
| Gratuit | Toute personne qui peut voir Orochia |
| Abonnés | Les abonnés approuvés du créateur |
| Contacts | Les contacts du créateur |
| Déblocage | Les personnes qui l’ont débloquée avec des crédits |
| Invités | Les personnes que le créateur a invitées |
| Enchère | Seulement le gagnant de son enchère |
| Contributeurs | Seulement les contributeurs du défi pour lequel elle a été faite |

Si vous ne pouvez pas regarder une vidéo, la page vous dit pourquoi et quoi faire. Les vidéos pour adultes demandent aussi un compte connecté dont l’âge a été vérifié. Voyez [Sécurité et règles 18+](/docs/safety).

## Suivre un créateur

1. Ouvrez la page du créateur.
2. Choisissez **Suivre**.
3. Le créateur approuve ses abonnés. Tant qu’il n’a pas accepté, votre demande est en attente.

Une fois que le créateur vous a accepté, ses vidéos réservées aux abonnés s’ouvrent pour vous. Vous pouvez vous désabonner à tout moment.

## Stories

Les stories sont courtes et durent 24 heures. Un anneau autour de la photo d’un créateur signale une story que vous n’avez pas encore vue. Ouvrez-la, touchez à droite pour la suivante et à gauche pour la précédente.

## Contacts et messages

Un contact est un lien dans les deux sens : une personne demande, l’autre accepte. Un créateur peut réserver des vidéos à ses contacts.

Vous décidez qui peut vous écrire dans **Paramètres, Confidentialité**. Les comptes que vous bloquez ne peuvent pas vous écrire, vous suivre ni vous demander en contact. Vous les gérez dans **Paramètres, Comptes bloqués**. Les conversations et les groupes sont expliqués dans [Messages et groupes](/docs/messages).

## Débloquer et laisser un pourboire

Quand une vidéo demande un déblocage, vous payez au moins le montant affiché. Voyez [Crédits, pourboires et déblocages](/docs/credits).
